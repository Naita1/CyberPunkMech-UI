## 🇧🇷 Versão em Português

## 🤖 Visão Geral
O CyberpunkMech Web é o front-end em React + Vite e Tailwind CSS do projeto CyberpunkMech. O sistema traz uma interface gráfica futurista com tema neon para navegação, controle da garagem de Mechs e conexão direta com a API REST do backend.

### ✨ Funcionalidades Prontas
- [x] **Landing Page Temática:** Interface com visual cyberpunk, tipografia futurista e botões estilizados com Tailwind CSS.
- [x] **Navegação de Menus:** Estrutura para Perfil, Configurações, Garagem e Sobre.
- [x] **Design Responsivo:** Adaptável para desktops e dispositivos móveis.
- [x] **Integração com API REST:** Estrutura pronta para comunicação com o backend em Spring Boot na porta 8080.
- [x] **Estilo Futurista:** Paleta neon, overlays escuros e elementos visuais inspirados em estética cyberpunk.

---

## 🛠 Tech Stack
- **Front-end & Build:** React 18 + Vite
- **Estilização:** Tailwind CSS + PostCSS
- **Linguagem:** JavaScript (ES6+)
- **Gerenciador de Dependências:** NPM

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
- [Node.js](https://nodejs.org/) (v18 ou superior)
- Backend rodando: [CyberPunkMech-API](https://github.com/Naita1/CyberPunkMech-API)

### 1. Clonar o Repositório
```bash
git clone https://github.com/Naita1/CyberPunkMech-Web.git
cd CyberPunkMech-Web
```

### 2. Instalar as Dependências
```bash
npm install
```

### 3. Rodar o Projeto em Desenvolvimento
```bash
npm run dev
```

O projeto ficará disponível em:
```bash
http://localhost:5173
```

### 4. Build para Produção
```bash
npm run build
```

## 🇺🇸 English Version

## 🤖 Overview
CyberpunkMech Web is the React + Vite + Tailwind CSS front-end for the CyberpunkMech project. It delivers a futuristic neon-themed interface for navigation, Mech garage control, and direct communication with the REST API backend.

### ✨ Implemented Features
- [x] **Thematic Landing Page:** Cyberpunk-style interface with futuristic typography and Tailwind-designed action buttons.
- [x] **Menu Navigation:** Structure for Profile, Settings, Garage, and About sections.
- [x] **Responsive Design:** Adapted for desktop and mobile screens.
- [x] **REST API Integration:** Ready for communication with the Spring Boot backend on port 8080.
- [x] **Futuristic Visual Style:** Neon palette, dark overlays, and visual elements inspired by cyberpunk aesthetics.

---

## 🛠 Tech Stack
- **Front-end & Build:** React 18 + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Language:** JavaScript (ES6+)
- **Dependency Manager:** NPM

### Prerequisites
